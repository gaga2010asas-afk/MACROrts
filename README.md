# 🎮 MACROrts — Tactical 3D Voxel Strategy

![Version](https://img.shields.io/badge/version-6.0.0--archive-blue)
![Platform](https://img.shields.io/badge/platform-Android-green)
![Engine](https://img.shields.io/badge/engine-Three.js-orange)

**MACROrts** — это полноценная 3D-стратегия в реальном времени (RTS-lite) для смартфонов, переносящая вас в атмосферу Второй мировой войны. 

Игра написана на ванильном JavaScript (ES-модули), Three.js и Capacitor.

## ✨ Основные фичи
*   **4 фракции** (Коминтерн, Ось, Союзники, Китайский фронт).
*   **Воксельная графика**: уникальные 3D-модели танков, самолетов и зданий.
*   **Стиль "Секретный архив"**: интерфейс состаренной бумаги, печати и радиосвязь.
*   **11 языков**.
*   **Полный офлайн-режим**.

## 🛠 Инструменты разработки (Made with)
Эта игра — результат работы не только рук, но и собственных AI-инструментов разработчика:
*   🧠 **[GAGA Vibe Studio Code (GVSC)](ссылка_на_репо_GVSC)** — AI-First IDE для генерации кода через VIBE-скрипты.
*   🎨 **[PAI Studio](ссылка_на_репо_PAI)** — собственный движок для генерации 3D-воксельной графики.
